15분 카페 체험 안내

과학 4학년 생물과 환경 승인팩0.1.3 · 104문항을 사용할 수 있어요. 최초·복습·숙달·재출제 모두 정답마다 해금 메뉴별 +1 생산 판정을 적용해요. 창고가 꽉 차면 더 보관되지 않아요. 오답은 생산0이고 해설을 확인해요. 같은 출제 기회는 중복 생산하지 않아요.

v2.6 과학 RC4 학생 테스트판입니다. 공식 v2.0.0과 저장이 분리됩니다. 로그인·실명 입력은 필요 없어요.

어떤 모드로 놀까요?

CLASS · 수업 게임: 매번 Lv.1에서 시작하는 15분 단판이에요. 문제를 풀고 재고를 만든 뒤 서빙하고 성장해요. 회차의 카페는 다음 판으로 이어지지 않아요.

GROWTH · 내 카페 키우기: 15분씩 카페를 이어서 키워요. 마을과 분점은 레벨이 오르면 열려요. 처음에는 기본 기능만 보여요.

  1. 모드와 오늘 공부할 수학·국어·과학를 골라요.
  2. 음식 만들기에서 문제를 풀어요. 맞히면 음식이 생겨요.
  3. 직원 0명이면 서빙하기를 눌러요. 직원이 있으면 자동 서빙해요.
  4. 15분 뒤 학습 결과와 오답 복습지를 확인하고 저장해요.
  5. GROWTH는 다시 접속해 카페가 이어지는지 확인해요.

과학 복습

오답 뒤 다른 문제3~5개를 풀면 같은 개념 복습이 나와요. 성공하면 다른 문제6~10개 뒤 숙달 확인을 해요. 후보가 부족하거나 예약이 몰리면 간격 조정이 결과에 표시돼요. GROWTH에서는 남은 예약이 다음 영업으로 이어져요. 최초 정답률은 복습 성공으로 바뀌지 않아요.

저장과 가져오기

다른 사이트의 저장은 자동으로 옮겨지지 않아요. 이 테스트판은 RC3와도 저장이 분리돼요. v2.6 RC3 전용 JSON 백업을 복사해 복원할 수 있어요. 이전 로컬 v2.6에서 백업을 받은 뒤 이곳 GROWTH의 기록과 백업 → 백업 복원에서 가져와요. 원본 백업은 남겨 두세요.

공식 v2.0.0·v2.5 백업은 이번 테스트판에서 지원하지 않아요. 원래 사이트에서 계속 보관해 주세요. 기기·브라우저를 바꾸거나 브라우저 저장을 삭제하면 백업 없이는 복구할 수 없어요.

문제가 생기면

초기화하거나 저장을 삭제하지 말고 선생님께 알려 주세요. 가능하면 먼저 JSON 백업을 받아요. 복원 실패 시 원래 저장을 유지해요. 여러 탭을 닫고 한 창에서 다시 시도하세요.

GROWTH 중 새로고침해도 원래 종료 시각은 늘어나지 않아요. 문제풀이 중에도 시간이 흘러요. CLASS는 새로고침 후 회차 복구를 지원하지 않으므로 영업 중에는 새로고침하지 마세요.

분점은 자격을 채운 본점 영업 완료 때만 정산해요. 창을 닫아 둔 시간은 수익이 되지 않아요.
